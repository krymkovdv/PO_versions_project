# Система управления версиями программного обеспечения для тракторов

## Общее описание

Это веб-приложение на основе FastAPI предназначено для управления версиями программного обеспечения и компонентами тракторов. 
Система предоставляет возможности аутентификации пользователей, управления тракторами, программным обеспечением, 
компонентами и поддержкой технического взаимодействия.

## Архитектура проекта

Проект организован по принципу разделения ответственности на несколько основных слоев:
- API уровень (в папке api)
- Уровень доступа к данным (в папке crud)
- Модели данных (в файле models.py)
- Схемы данных (в файле schemas.py)

## Описание файлов проекта

### Корневые файлы

- `Dockerfile` - конфигурация контейнера для запуска приложения
- `requirements.txt` - зависимости Python проекта
- `alembic.ini` - конфигурация миграций базы данных
- `filldb.py` - скрипт для заполнения базы данных тестовыми данными
- `filluser.py` - скрипт для создания пользователей
- `request.py` - примеры запросов к API

### Папка `app`

#### Файлы приложения

- `app/main.py` - основной точкой входа в приложение, настройка CORS и регистрация маршрутов
- `app/config.py` - конфигурационные параметры приложения
- `app/database.py` - настройка соединения с базой данных
- `app/models.py` - определение ORM моделей SQLAlchemy
- `app/schemas.py` - определение Pydantic схем для валидации данных
- `app/authorization.py` - логика авторизации и проверки прав пользователей
- `app/log.py` - настройка логирования приложения
- `app/log_context.py` - контекстное логирование

#### Папка `app/api`

- `app/api/auth.py` - маршруты аутентификации (регистрация, вход, получение токенов)
- `app/api/users.py` - маршруты управления пользователями
- `app/api/tractors.py` - маршруты управления тракторами (получение, создание, обновление, удаление)
- `app/api/components.py` - маршруты управления компонентами тракторов
- `app/api/software.py` - маршруты управления программным обеспечением
- `app/api/support.py` - маршруты поддержки (сообщения, ответы)
- `app/api/search.py` - маршруты поиска и фильтрации данных

#### Папка `app/crud`

- `app/crud/users.py` - функции работы с пользователями в базе данных
- `app/crud/tractors.py` - функции работы с тракторами в базе данных
- `app/crud/components.py` - функции работы с компонентами в базе данных
- `app/crud/software.py` - функции работы с программным обеспечением в базе данных
- `app/crud/software_component_link.py` - функции работы с связями между ПО и компонентами
- `app/crud/tractor_software_component_link.py` - функции работы с связями между тракторами, ПО и компонентами
- `app/crud/support.py` - функции работы с сообщениями поддержки
- `app/crud/search.py` - функции поиска и фильтрации данных
- `app/crud/chat.py` - функции чата (если используется)

## Бизнес-процессы

### Управление пользователями
Система поддерживает три роли пользователей:
- `engineer` - инженер, имеет ограниченный доступ к информации
- `dealer` - дилер, может просматривать информацию о тракторах
- `moderator` - модератор, имеет права на изменение и добавление информации

### Управление тракторами
Позволяет добавлять, обновлять, удалять и просматривать информацию о тракторах:
- Модель трактора
- VIN номер
- Количество моточасов
- Дата последней активности
- Регион эксплуатации
- Потребитель и дилер

### Управление компонентами
Система позволяет управлять различными типами компонентов тракторов:
- DVS - двигатель внутреннего сгорания
- KPP - коробка передач
- RK - раздаточная коробка
- HR - ходовая часть
- BK - тормозная система
- AUTOPILOT - система автоматического управления

### Управление программным обеспечением
Система позволяет управлять версиями программного обеспечения для компонентов:
- Загрузка новых версий ПО
- Установка статуса (серийное, опытное, в эксплуатации)
- Актуальность и критичность обновлений
- Привязка к моделям тракторов

### Поиск и фильтрация
Реализованы сложные механизмы поиска и фильтрации:
- Поиск по компонентам с фильтрами по моделям тракторов, типам компонентов, производителям
- Поиск тракторов по компонентам и их ПО
- Расширенные фильтры по статусу ПО, дате сборки и другим параметрам

### Поддержка
Система поддержки позволяет пользователям обмениваться сообщениями:
- Создание новых обращений
- Ответы на существующие сообщения
- Отслеживание статуса сообщений (прочитано/не прочитано)
- Возможность закрытия обращений

## Запуск приложения

### Локальный запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите миграции: `alembic upgrade head`
3. Запустите приложение: `uvicorn app.main:app --reload`
4. Приложение будет доступно по адресу: `http://localhost:8000`

### Запуск в Docker
1. Соберите образ: `docker build -t po_versions_project .`
2. Запустите контейнер: `docker run -p 8000:8000 po_versions_project`

## Структура базы данных

Система использует следующие основные таблицы:
- `users` - информация о пользователях
- `tractors` - информация о тракторах
- `components` - компоненты тракторов
- `softwares` - программное обеспечение
- `software_component_links` - связи между ПО и компонентами
- `tractor_software_and_component_links` - связи между тракторами, ПО и компонентами
- `support_message` - сообщения поддержки
- `message_read_status` - статусы прочтения сообщений

## API Endpoints

Основные API эндпоинты:
- `/auth/login` - аутентификация пользователя
- `/users` - управление пользователями
- `/tractors` - управление тракторами
- `/components` - управление компонентами
- `/software` - управление программным обеспечением
- `/search` - поиск и фильтрация данных
- `/support` - поддержка и сообщения
